# Contexto del proyecto PICA

## Descripción

PICA es el concepto de una página promocional y tienda demostrativa para gomitas enchiladas. La dirección visual combina tipografía contundente, colores cálidos, formas inspiradas en dulces y chile, y navegación sencilla para público joven.

## Objetivos del sitio

1. Presentar el producto con una identidad visual propia.
2. Organizar el contenido en páginas independientes para mantenerlo con facilidad.
3. Mostrar opciones de producto y un flujo de carrito demostrativo.
4. Dar contexto al trabajo y mostrar el equipo creador.
5. Practicar estructura semántica, responsive design, metadatos SEO y JavaScript.

## Limitaciones del prototipo

El navegador almacena el carrito localmente. El botón de compra abre WhatsApp con el detalle y subtotal como mensaje preparado; la persona debe revisarlo y enviarlo. El sitio no cobra ni confirma inventario, entrega o total final; esos datos se acuerdan por WhatsApp. El formulario de contacto valida campos y muestra una confirmación, pero no envía ni almacena mensajes. Los precios y presentaciones deben validarse antes de cualquier publicación o venta.

## Mantenimiento

- Edita `PRODUCTS` en `assets/js/site.js` para cambiar productos y precios de muestra.
- Edita `assets/css/site.css` para la identidad visual y los breakpoints responsive.
- Conserva el menú y el pie coherentes en cada página HTML.
- Mantén títulos y metadescripciones específicos en cada archivo HTML.
